# 使用手册（USAGE）

把任意网页视频放进一个**可以随意拖拽宽高的画中画浮动小窗**，边看边干别的。

## 安装（1 分钟）

1. 打开 Chrome，地址栏输入 `chrome://extensions/` 回车
2. 打开右上角的「开发者模式」开关
3. 点击左上角「加载已解压的扩展程序」
4. 选择仓库里的 **`extension/`** 文件夹（里面要有 manifest.json）；或先解压 [`releases/video-pip-plus-v1.2.0.zip`](../releases/video-pip-plus-v1.2.0.zip) 再选择解压出的文件夹
5. 建议：点浏览器右上角拼图图标 🧩，把「视频画中画 Plus」图钉固定到工具栏

> Edge 用户：打开 `edge://extensions/`，同样开启开发者模式后加载，步骤一致。

## 三种开启方式

| 方式 | 操作 |
|---|---|
| 悬浮按钮（推荐） | 鼠标悬停到视频上，点左上角出现的「画中画」按钮 |
| 工具栏弹窗 | 点扩展图标 → 「开启画中画」 |
| 快捷键 | `Alt + P` |
| 右键菜单 | 在视频上右键 → 「画中画播放」 |

再按一次 `Alt + P` 或点小窗右下角 ↩ 按钮，视频放回页面原位置。

## 调整宽度和高度（核心功能）

- **拖拽小窗的四条边、四个角**即可自由改变宽度和高度，互不锁定比例
- 松手后尺寸**自动记住**，下次开启直接用
- 如果浏览器开启时忽略了记忆尺寸，窗口中央会出现「应用上次尺寸 W × H」按钮，点一下即恢复
- 双击任意角落恢复默认尺寸（512 × 320）
- 也可以在扩展弹窗里直接输入精确的宽/高数值保存

小窗内还有：播放/暂停、进度拖动、音量与静音、实时尺寸显示；直播流会显示「直播」并自动禁用进度条。

## 视频解析下载（右下角 ⭳ 按钮）

画中画小窗控制条最右侧（返回按钮旁）有一个下载按钮，点击即解析当前视频并下载：

| 视频类型 | 行为 |
|---|---|
| http(s) 直链（mp4/webm 等） | 调用浏览器下载器后台下载，自动命名，可在浏览器下载管理器查看进度 |
| m3u8 / HLS（含 AES-128 加密） | **自动解析播放列表 → 并发下载全部分片 → 解密 → 合并为 .ts 文件**；master 多码率自动选最高清；支持 fMP4 初始化段 |
| MSE 流式（边下边播，如 B 站 / YouTube 常规播放） | 自动嗅探页面里的 m3u8 地址并走解析下载；若页面还没加载出 m3u8，先播放几秒再点下载 |
| 同源 blob 视频 | 读取视频数据后用浏览器另存，文件名取页面标题 |
| 直播 / 摄像头流（srcObject） | 提示无法下载 |

## 常见问题（FAQ）

- **弹窗提示「此页面不支持画中画」？** 你在浏览器内置页面（chrome://、应用商店、PDF 查看器等）上使用，这些页面禁止扩展注入，请切换到普通网页。
- **扩展是刚安装/重新加载的，旧标签页没反应？** 新版会自动连接：打开扩展弹窗即自动向当前页面补装脚本，无需刷新。若仍提示异常，刷新一次页面即可。
- **本地文件（file://）页面没有按钮？** 在 `chrome://extensions/` 本扩展详情里打开「允许访问文件网址」。
- **Netflix 等付费视频？** 受 DRM 版权保护，浏览器禁止画中画和下载，属正常限制。
- **下载的视频播不了 / 提示不支持？** DRM 加密视频（Netflix 等）无法下载。m3u8 下载产物为 .ts 格式，现代播放器（PotPlayer、VLC）可直接播放；若需要 mp4 可用 ffmpeg 转封装：`ffmpeg -i 文件.ts -c copy 文件.mp4`。SAMPLE-AES 等 DRM 加密的 m3u8 不支持。
- **下载在哪？** 打开浏览器右上角 ⬇ 下载图标（或 Ctrl+J）查看进度；默认保存到系统「下载」文件夹。
- **B 站点了下载没反应？** 页面还没加载出 m3u8 播放列表，先让视频播放几秒再点下载。
- **chrome:// 或应用商店页面？** 浏览器内置页面禁止扩展注入，不支持。

## 修改指南（想改什么 → 改哪里）

| 想改什么 | 改哪里 |
|---|---|
| 默认窗口尺寸 | `extension/content.js` 开头 `DEFAULT_W` / `DEFAULT_H` |
| 最小尺寸限制 | `extension/content.js` 开头 `MIN_W` / `MIN_H` |
| 小窗配色/控制条样式 | `extension/content.js` 里的 `PIP_CSS` |
| 悬浮按钮样式 | `extension/content.css` 的 `#__vpip_hover_btn` |
| 下载按钮行为 | `extension/content.js` 的 `resolveVideoSource` / `handleDownload` |
| m3u8 并发数 / 重试次数 | `extension/offscreen.js` 的 `CONC` / `fetchBuf` 的 `retries` |
| 快捷键 | `chrome://extensions/shortcuts` 页面设置 |
| 弹窗文字/布局 | `extension/popup.html` / `popup.css` |

改完后在 `chrome://extensions/` 点本扩展的「重新加载」↻ 即可生效。

## 质量说明

已用 Chrome for Testing 152（Chromium 内核，与 Chrome 行为一致）自动化实测 25 项全部通过（清单见 [TESTING.md](TESTING.md)）。

技术要点：优先使用 Document Picture-in-Picture API（自定义窗口，可编程调宽高）；iframe 内视频或旧内核自动回退到原生 `requestPictureInPicture()`（系统窗口同样支持拖拽边角调大小）。
